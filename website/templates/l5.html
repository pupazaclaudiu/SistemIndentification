Formularea CMMP offline

Pentru fiecare eșantion n ≥ max(na, nb) se definește vectorul de regresori:

φT(n) = [ −y[n−1], …, −y[n−na], u[n−1], …, u[n−nb] ]

Θ = [ a1, …, ana, b1, …, bnb ]T

Se construiesc:

Φ = [ φT(n) ] – matricea de regresori (Neff × (na+nb))

Y = [ y(n) ] – vectorul ieșirilor corespunzătoare

Estimatorul celor mai mici pătrate (CMMP offline) este:

Θ̂ = (ΦT Φ)−1 ΦT Y

{% endblock %} {# ===================== CARD: Interpretare / ieșire estimată ===================== #} {% block stats2 %}
Interpretarea rezultatelor

Odată estimați coeficienții ai și bj, modelul ARX poate fi utilizat pentru simularea ieșirii sistemului:

ŷ[n] = −a1 y[n−1] − … − ana y[n−na] + b1 u[n−1] + … + bnb u[n−nb]

Suprapunerea lui y[n] și ŷ[n] în grafic permite evaluarea calității identificării (cât de bine urmărește modelul comportarea sistemului real).
