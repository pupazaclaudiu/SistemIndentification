Ecuația Wiener–Hopf (forma discretă)

Metoda deconvoluţiei pornește de la legătura dintre intercorelația intrare–ieșire și autocorelația intrării:

Ruy(kΔ) ≈ Σ h(iΔ) · Ru((k − i)Δ)

k = 0, 1, …, nh − 1

În formă matricială, sistemul de ecuații se scrie:

Φu · H = Φuy

H = [h(0), h(Δ), …, h((nh−1)Δ)]T

{% endblock %} {# Card: cum calculăm Ru, Ruy și h(k) #} {% block stats2 %}
Relațiile de calcul pentru L4

Pentru un semnal de intrare u[n] și ieșire y[n] (n = 0…N−1), se calculează:

Ru(k) ≈ (1/N) · Σ u(i) · u(i + k)

Ruy(k) ≈ (1/N) · Σ u(i) · y(i + k)

pentru k = 0, 1, …, nh − 1

Matricea Φu este o matrice Toeplitz construită din valorile autocorelației Ru(k), iar Φuy este vectorul cu valorile Ruy(k):

Φu(i,j) = Ru(|i − j|),   i,j = 0…nh−1

Φuy(i) = Ruy(i),   i = 0…nh−1

Funcția pondere (secvența de ponderare) se obține rezolvând:

H = Φu−1 · Φuy
