Sumatori pentru regresie

Pentru N perechi (ui, yi), definim:

Su = ∑ ui

Sy = ∑ yi

Suy = ∑ ui · yi

Su² = ∑ ui2

Ecuațiile normale ale regresiei liniare:

a · N + b · Su = Sy

a · Su + b · Su² = Suy

{% endblock %} {% block stats2 %}
Formulele explicite pentru a și b

Din sistemul de ecuații normale rezultă:

a = (Su · Suy − Su² · Sy) / (Su2 − N · Su²)

b = (Suy · N − Su · Sy) / (Su² · N − Su2)
