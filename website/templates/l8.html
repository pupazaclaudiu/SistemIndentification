{% endblock %} {# ===================== CARD 3: Formule rețea NN ===================== #} {% block stats1 %}
Modelul matematic al rețelei

Vectorul de intrare la momentul n:

x(n) = [ u(n), u(n−1), u(n−2) ]ᵀ

Stratul ascuns calculează:

h = ϕ(W₁ · x + b₁)

Stratul de ieșire produce predicția:

ŷ(n) = W₂ · h + b₂

unde ϕ este funcția de activare neliniară (de tip tanh), W₁, W₂ sunt matricile de ponderi iar b₁, b₂ vectorii de bias.

{% endblock %} {# ===================== CARD 4: Antrenarea (backprop + gradient desc.) ===================== #} {% block stats2 %}
Antrenarea rețelei (CMMP neliniar)

Rețeaua este antrenată prin minimizarea funcției de cost (de tip MSE) pe setul de date:

J = (1/N) · Σ ( y(n) − ŷ(n) )²

Ponderile se actualizează iterativ prin algoritmul backpropagation cu gradient descendent (solver „adam”).

După antrenare, rețeaua poate fi folosită ca model al sistemului: pentru orice secvență nouă u[n], se formează vectorul x(n) și se calculează ŷ(n) ≈ răspunsul sistemului.
