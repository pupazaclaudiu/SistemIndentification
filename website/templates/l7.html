Indicatori de calitate ai fitării

SSE – suma pătratelor reziduurilor (erorilor). Valoare mai mică → potrivire mai bună.

R² – coeficientul de determinare. Aproape de 1 → modelul explică bine variația datelor.

R² ajustat – R² corectat cu gradele de libertate; este indicatorul recomandat când compari modele cu grade diferite.

RMSE – eroarea medie pătratică rădăcină; aproximativ „eroarea tipică” pe punct. Mai mic → fit mai bun.

{% endblock %} {% block stats2 %}
Model polinomial de grad n

Se caută un polinom de forma:

y ≈ a₀ + a₁·x + a₂·x² + … + aₙ·xⁿ

Coeficienții ai se determină prin metoda celor mai mici pătrate, minimizând SSE = Σ (yi − ŷi)². Pentru fiecare grad 1…6 se calculează indicatorii de mai sus, iar modelul cu cel mai mare R² ajustat este considerat „cel mai bun” pentru domeniul de date ales.
